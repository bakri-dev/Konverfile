Ubah format gambar

Konversi JPG, PNG, dan WebP satu sama lain. Atur kualitas dan lebar maksimum sekaligus untuk kompres otomatis.

  • JPG → PNG, WebP
  • PNG → JPG, WebP
  • WebP → JPG, PNG
  • Kompres & resize sekaligus

Gambar ke PDF

Gabungkan beberapa gambar menjadi satu file PDF. Pilih ukuran halaman A4 atau biarkan menyesuaikan ukuran gambarmu.

  • Banyak gambar → 1 PDF
  • Halaman A4 atau sesuai gambar
  • Urutan bisa diatur
  • Tanpa watermark

Proses banyak sekaligus

Tidak perlu satu per satu. Pilih atau seret banyak file sekaligus dan unduh semua hasil konversi.

  • Drag & drop banyak file

  • Unduh satu per satu
  • Tanpa antrean

Cara pakai

Tiga langkah, selesai dalam hitungan detik.

  1. 1

    Pilih file

    Klik tombol "Pilih gambar" atau seret file langsung ke kotak di bawah. Bisa lebih dari satu sekaligus.

  2. 2

    Tentukan format tujuan

    Pilih format keluaran dan atur kualitas atau ukuran jika perlu. Untuk PDF, pilih ukuran halamannya.

  3. 3

    Unduh hasilnya

    Klik "Ubah" dan unduh file hasil konversi. Semua proses berlangsung di perangkatmu — tidak ada yang dikirim ke mana pun.
